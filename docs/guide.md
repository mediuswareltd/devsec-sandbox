# Guide

## What it is

An educational security lab with vulnerable and fixed demos for common web/app security issues.

## Stack

`Node.js`, `HTML`, `Security labs`

## Capabilities

### 14 demos

Broken access, injection, XSS, and more.

### Vulnerable + fixed

Side-by-side broken and remediated versions.

### Zero deps

Node built-ins only for server demos.

### Dashboard

index.html home to launch labs.
