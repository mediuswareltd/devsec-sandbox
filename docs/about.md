# About DevSec Sandbox

## Who maintains it

DevSec Sandbox is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/devsec-sandbox](https://github.com/mediuswareltd/devsec-sandbox).

## Why it exists

An educational security lab with vulnerable and fixed demos for common web/app security issues.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/devsec-sandbox/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
