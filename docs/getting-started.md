# Getting started

Install and run **DevSec Sandbox** locally.

## Prerequisites

- Working knowledge of HTML / Node
- Git and a terminal

## Install

```bash
git clone https://github.com/mediuswareltd/devsec-sandbox.git
cd devsec-sandbox
```

## Quick start

```bash
node start-all.js
# then open index.html
```
