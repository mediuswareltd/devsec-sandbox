For educational use only. Run on localhost. Do not deploy vulnerable servers on a public or shared network.
Quick Start node start-all.js Starts all 22 servers simultaneously (11 vulnerable + 11 fixed, on separate ports). Then open the dashboard links below. HTML-only demos (07, 12, 13, 14) open directly in the browser.
